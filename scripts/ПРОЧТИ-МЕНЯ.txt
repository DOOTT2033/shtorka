Шторка 0.0.2 — Windows x64
==========================

Что в папке
-----------
Shtorka.exe           — клиент (окно чата)
Shtorka-Server.exe    — лаунчер сервера (окно с портом, адресами и логами)
server.exe            — сервер без окна (для запуска из консоли / автозапуска)
installers\           — установщики MSI и EXE (ставят ярлык в меню Пуск)

Быстрый старт
-------------
1. Запустите Shtorka-Server.exe на компьютере, который будет сервером.
2. В окне лаунчера нажмите «Запустить» (порт по умолчанию 7878).
3. Скопируйте адрес из списка (например ws://192.168.1.5:7878) кнопкой «Копировать».
4. На других ПК запустите Shtorka.exe, вставьте этот адрес в поле «Адрес сервера»
   и нажмите «Зарегистрироваться» (имя + пароль от 4 символов).
5. Для игры через Radmin VPN используйте адрес с пометкой «Radmin VPN».

Важно
-----
- Портативная сборка хранит данные рядом с Shtorka-Server.exe: config.toml, data\server.db,
  data\files\. Скопируйте всю папку, чтобы перенести историю и аккаунты.
- Если лаунчер установлен установщиком (Program Files), данные лежат в
  %LOCALAPPDATA%\Shtorka\server (туда не нужны права администратора).
- Повторный вход под тем же аккаунтом закрывает старую сессию.
- Аккаунты и история сохраняются после перезапуска, но сессии — нет:
  после рестарта сервера нужно войти заново (токен проверяется через /account).
- Файлы и фото доступны по ссылке /files/<id> без пароля — не публикуйте сервер
  в интернет, пока не выйдет версия с авторизацией файлов.
- Установщики можно не использовать: достаточно распаковать эту папку целиком.

Консольный запуск
-----------------
server.exe --port 7878 --data data
server.exe --help

Сборка из исходников
--------------------
powershell -ExecutionPolicy Bypass -File scripts\build_release.ps1
