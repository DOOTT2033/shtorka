Шторка 0.1.0 — Windows x64
==========================

Что в папке
-----------
Shtorka.exe           — клиент (окно мессенджера)
Shtorka-Server.exe    — лаунчер сервера (окно с портом, адресами и логами)
server.exe            — сервер без окна (для консоли / автозапуска)

Установщиков MSI и NSIS больше нет: всё работает из этой папки.

Быстрый старт
-------------
1. Запустите Shtorka-Server.exe на компьютере, который будет сервером.
2. В окне лаунчера нажмите «Запустить» (порт по умолчанию 7878).
3. Скопируйте адрес из списка (например ws://192.168.1.5:7878) кнопкой «Копировать».
4. На других ПК запустите Shtorka.exe, вставьте этот адрес в поле «Адрес сервера».
5. Зарегистрируйтесь: юзернейм (латиница, цифры и _, 3–20 символов), имя и пароль
   от 6 символов. Вход выполняется по юзернейму.
6. Для игры через Radmin VPN используйте адрес с пометкой «Radmin VPN».

Важно
-----
- Портативная сборка хранит данные рядом с Shtorka-Server.exe: config.toml,
  data\server.db, data\files\. Скопируйте всю папку, чтобы перенести историю и аккаунты.
- Повторный вход под тем же аккаунтом закрывает старую сессию.
- Аккаунты и история сохраняются после перезапуска, сессии — нет: после рестарта
  сервера нужно войти заново.
- Файлы и аватарки доступны только по ссылке с токеном (/files/<id>?token=...).
  Не публикуйте сервер в интернет без VPN.
- Visual C++ Redistributable не нужен: CRT полностью встроен в exe.
- Нужен WebView2 Runtime. В Windows 10/11 он обычно уже установлен. Если его нет,
  приложение покажет окно со ссылкой на установку.

Личные сообщения и приватность
------------------------------
- Найдите человека по юзернейму в поле поиска и откройте чат.
- В настройках → Приватность можно запретить личные сообщения и скрыть статус «в сети».
- Личные сообщения видят только отправитель и получатель.

Консольный запуск
-----------------
server.exe --port 7878 --data data
server.exe --help

Сборка из исходников
--------------------
powershell -ExecutionPolicy Bypass -File scripts\build_release.ps1
