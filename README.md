# Messenger

Собственный мессенджер на Rust. Пока — только текстовая переписка.

## Договорённости

- **Язык:** Rust (сервер и клиент).
- **Клиент:** Tauri 2 — один код собирается в **exe** (Windows) и **apk** (Android). Интерфейс на HTML/CSS/JS.
- **Сервер:** отдельный бинарник на Rust (tokio + WebSocket), хранит пользователей и историю сообщений.
- **Лаунчер сервера:** exe с небольшим окном — порт, кнопки «Запустить / Остановить», список адресов (локальный IP, IP Radmin VPN, публичный IP).
- **Сеть:** локальная сеть + Radmin VPN (или другая оверлей-сеть). Публичный IP / ретранслятор — позже.

## Структура (план)

```
messenger/
├── README.md
├── server/     # сервер: WebSocket, хранение сообщений
├── launcher/   # GUI-лаунчер сервера (exe)
├── client/     # клиент Tauri (exe + apk)
└── shared/     # общие типы сообщений (serde)
```

## Этапы

1. Сервер: подключение по WebSocket, отправка и приём текста.
2. Клиент: вход по имени, список контактов, окно чата.
3. Лаунчер сервера: запуск/остановка, показ адресов.
4. Сборка exe и apk, проверка через Radmin VPN.
5. Позже: публичный доступ, шифрование, история на диске.
