# Шторка

Собственный мессенджер на Rust. **0.1.0 — PROFILE & PERSONALIZATION UPDATE.**

## Что нового в 0.1.0

- **Юзернейм и имя отдельно.** Юзернейм — уникальный, только латиница, цифры и `_`
  (3–20 символов), вход по нему без учёта регистра. Отображаемое имя может быть любым:
  имя, фамилия, ник — до 40 символов.
- **Личные сообщения.** Поиск человека по юзернейму и переписка один на один.
  Личные сообщения получают только отправитель и получатель, в общий чат они не попадают.
- **Аватарки.** Загрузка PNG, JPEG, WebP или GIF до 5 МБ, показ в списке чатов и сообщениях.
- **Приватность.** Можно запретить личные сообщения (`everyone` / `nobody`) и скрыть
  статус «в сети». Запрет действует на сервере, а не только в интерфейсе.
- **Полноценные настройки:** профиль, оформление, уведомления, приватность, аккаунт.
- **Оформление:** тёмная, светлая и автоматическая тема, 6 акцентов, 5 обоев и своя
  картинка, три размера шрифта. Настройки сохраняются в `localStorage`.
- **Уведомления:** значок непрочитанных в списке чатов, счётчик в заголовке окна,
  системные уведомления и звук (включаются в настройках).
- **Новая иконка** приложения и исправленная иконка настроек.
- **Только exe, без MSI/NSIS.** Портативная сборка и отдельные exe для скачивания.
- **Без Visual C++ Redistributable.** Все exe собраны с полностью статическим CRT,
  включая UCRT: в зависимостях нет `vcruntime`, `msvcp` и `api-ms-win-crt`.
- **Оптимизированная release-сборка:** LTO, `opt-level=3`, `codegen-units=1`, strip.

## Системные требования

- Windows 10/11 x64.
- Microsoft Edge WebView2 Runtime. В Windows 10/11 он обычно уже установлен; если нет,
  приложение покажет окно с ссылкой на установку:
  <https://developer.microsoft.com/microsoft-edge/webview2/>.
- Visual C++ Redistributable **не нужен** — CRT встроен в exe.

## Быстрый старт

1. Распакуйте `Shtorka-0.1.0-win64.zip` в любую папку.
2. Запустите `Shtorka-Server.exe` на компьютере, который будет сервером.
3. В окне лаунчера нажмите «Запустить» (порт по умолчанию 7878) и скопируйте адрес
   вида `ws://192.168.1.5:7878`.
4. На других ПК запустите `Shtorka.exe`, укажите этот адрес и зарегистрируйтесь:
   юзернейм, имя и пароль от 6 символов.
5. Для игры через Radmin VPN используйте адрес с пометкой «Radmin VPN».

Портативная сборка хранит `config.toml`, `data\server.db` и `data\files\` рядом
с `Shtorka-Server.exe`. Скопируйте всю папку, чтобы перенести аккаунты и историю.

## API сервера

- `POST /register` — `{username, display_name, password}` → `{token, username, ...}` (201/400/409).
- `POST /login` — `{username, password}` → профиль и токен (401/404).
- `POST /logout` — `{token}` — завершить сессию.
- `POST /password` — `{token, old, new}` — смена пароля.
- `POST /profile` — `{token, display_name, dm_privacy, show_online}` — профиль и приватность.
- `GET /account?token=` — текущий профиль.
- `GET /users?token=&q=` — поиск пользователей по юзернейму.
- `GET /ws?username=&token=` — WebSocket чата и личных сообщений.
- `GET /history?token=` — последние сообщения общего чата.
- `POST /upload?token=&name=&mime=` — загрузка файла (до `max_upload_mb` МБ).
- `POST /avatar?token=` / `DELETE /avatar?token=` — аватарка.
- `GET /files/:id?token=` — файл или аватарка; без токена доступа нет.
- `GET /health` — проверка, что сервер жив.

## Сборка

```
powershell -ExecutionPolicy Bypass -File scripts\build_release.ps1
```

Скрипт прогоняет тесты всего workspace, собирает `server.exe`, `Shtorka.exe` и
`Shtorka-Server.exe` без установщиков, проверяет через `dumpbin`, что exe не зависят
от `vcruntime`, `msvcp` и `api-ms-win-crt`, и складывает в `dist/` портативную папку, zip и `SHA256SUMS.txt`.
