# Шторка 0.1.0

Профили, личные сообщения и оформление. Только портативные exe — без MSI и NSIS.

## Что нового

### Профиль
- Уникальный **юзернейм** (`@alice`) — только латиница, цифры и `_`, 3–20 символов.
  Вход по юзернейму без учёта регистра.
- Отдельное **отображаемое имя** — любой текст до 40 символов (например, «Алиса Тестова»).
- Загрузка **аватарки**: PNG, JPEG, WebP, GIF до 5 МБ. Смена и удаление в настройках.

### Личные сообщения
- Поиск людей по юзернейму.
- Переписка один на один. Сообщения получают только отправитель и получатель,
  они не транслируются в общий чат.
- Непрочитанные: счётчик в списке чатов и в заголовке окна, системные уведомления.

### Приватность
- `dm_privacy`: `everyone` — личные сообщения разрешены, `nobody` — запрещены.
- `show_online`: можно скрыть статус «в сети» от других.
- Запрет проверяется на сервере: отправитель получает ошибку
  «Пользователь запретил личные сообщения».

### Оформление
- Темы: тёмная, светлая, автоматическая.
- 6 акцентов.
- 5 обоев, «Без обоев» и своя картинка.
- Три размера шрифта.
- Настройки сохраняются между запусками.

### Надёжность и сборка
- Все exe собраны с **полностью статическим CRT** (включая UCRT): Visual C++
  Redistributable не нужен, зависимостей `vcruntime`/`msvcp`/`api-ms-win-crt` нет.
- Release-профиль: LTO, `opt-level=3`, `codegen-units=1`, strip.
- Если WebView2 не установлен, приложение показывает понятное окно со ссылкой на установку.
- Прогнаны `cargo test --workspace` (12 API-тестов, 4 теста launcher, 4 теста shared)
  и ручные проверки интерфейса: регистрация, чат, личные сообщения, приватность,
  аватарки, поиск, настройки, переподключение.

## Файлы

| Файл | Назначение |
| --- | --- |
| `Shtorka.exe` | клиент мессенджера |
| `Shtorka-Server.exe` | лаунчер сервера с окном и логами |
| `server.exe` | сервер без окна (консоль / автозапуск) |
| `Shtorka-0.1.0-win64.zip` | всё вместе + инструкция |
| `SHA256SUMS.txt` | контрольные суммы |

## Установка

Установщиков нет. Распакуйте zip и запустите `Shtorka-Server.exe` на сервере,
затем `Shtorka.exe` на клиентах. Данные сервера лежат рядом с exe в `config.toml`
и `data\`.

Нужен Windows 10/11 x64 и WebView2 Runtime (в Windows 10/11 обычно уже есть).
Visual C++ Redistributable не требуется.

## Известные ограничения

- Сервер рассчитан на локальную сеть или Radmin VPN; публичного ретранслятора пока нет.
- Трафик WebSocket не шифруется на уровне приложения — используйте доверенную сеть/VPN.
- Мобильного клиента в этой версии нет.
